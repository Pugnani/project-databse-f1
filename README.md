# Formula 1 Database Management System

A database management and analysis system designed to store and manage data for a single **Formula 1 season**.

The project covers the main phases of database development, from conceptual modeling using an Entity-Relationship (E-R) schema to logical design and relational mapping. The database is implemented in **MySQL** and integrated with a **Java application using JDBC**.

## Project Structure

- `databaseprojF1.pdf` — Documentation describing the different phases of the project, including database design and modeling.
- `F1Database.java` — Java application implementing database connectivity and interaction through JDBC.
- `tabel_construction.sql` — SQL script for creating the database tables and defining their structure.
- `populating_database.sql` — SQL script for populating the database with data.

## Technologies Used

- **MySQL** — Relational database management system.
- **Java** — Application development.
- **JDBC** — Connectivity between the Java application and the database.
- **SQL** — Database definition and data manipulation.
